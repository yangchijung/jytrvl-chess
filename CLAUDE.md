# Claude Project Instructions

Before changing any public interface in jytrvl-chess, read `DESIGN.md` in full.

`DESIGN.md` is mandatory implementation policy, not optional visual inspiration. Apply it to new screens, component changes, copy, empty/error/loading states, desktop, and mobile. Before completing UI work, state internally:

1. The user task and primary action improved.
2. Why the composition is appropriate for this product instead of a generic AI dashboard.
3. Which constraints from `DESIGN.md` affected the implementation.
4. Accessibility and mobile checks performed.

Do not introduce forbidden gradients, glass surfaces, decorative shadows, excess pills, emoji decoration, generic AI copy, or non-functional visual effects. If a visual element cannot be justified by a real user task or content, remove it.
