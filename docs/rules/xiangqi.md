# JY Games 台灣象棋規則 v1.0

本文件固定 JY Games 中國象棋採用的規則版本。規則引擎 `shared/games/xiangqi/rules.ts` 與自動化測試 `tests/xiangqi.test.ts` 以本文件為準。

參考依據：台灣常見對局習慣，以及亞洲象棋聯合會（AXF）《象棋比賽規則》中長將、長捉的基本精神。完整的 AXF 裁判細則（例如「一將一捉」「多子捉」的逐條例外）需要人工裁判；線上系統採用下列可機器判定的簡化版本，並在遊戲內「規則說明」完整公開。

## 1. 棋盤與棋子
- 9 路 × 10 線，中間為楚河漢界；紅方在下、先行。
- 紅：帥、仕×2、相×2、俥×2、傌×2、炮×2、兵×5；黑：將、士×2、象×2、車×2、馬×2、包×2、卒×5。

## 2. 走法
| 棋子 | 走法 | 限制 |
|---|---|---|
| 帥／將 | 直或橫走一格 | 不得出九宮 |
| 仕／士 | 斜走一格 | 不得出九宮 |
| 相／象 | 斜走兩格（田字） | 不得過河；田字中心有子即「塞象眼」不能走 |
| 俥／車 | 直橫任意格 | 不得越子 |
| 傌／馬 | 先直一格再斜一格（日字） | 直走方向的相鄰點有子即「蹩馬腿」 |
| 炮／包 | 移動同車 | 吃子必須隔一子（炮架）；炮架可為任一方棋子 |
| 兵／卒 | 未過河只能前進一格；過河後可前進或橫走一格 | 永不後退 |

## 3. 將帥不得照面
任何一步走完後，帥與將在同一直線且中間無子，該步為非法。

## 4. 將軍與應將
- 走完後己方帥（將）被攻擊（含照面）的著法一律非法。
- 被將軍時必須應將。

## 5. 勝負
1. **將死**：輪走方被將軍且無合法著法 → 輪走方負。
2. **困斃**：輪走方未被將軍但無任何合法著法 → 輪走方負（象棋困斃判負，與西洋棋不同）。
3. 認輸、超時（見 §8）。

## 6. 重複局面裁決（長將、長捉）
當同一局面（棋子位置＋輪走方）出現第 **3** 次時，系統檢查自該局面第一次出現以來的循環：

1. **長將**：一方在循環中每一步都將軍，另一方不是 → 長將方判負。雙方皆長將 → 和局。
2. **長捉**：一方在循環中每一步都「將軍或捉子」，另一方不是 → 該方判負。雙方皆如此 → 和局。
3. 其餘情況（閒著循環）→ 和局。

「捉」的機器判定（簡化版）：
- 走子後，剛走動的棋子可合法吃掉的對方棋子，且符合下列任一條件：
  - 目標無合法保護（對方無法合法吃回），或
  - 以價值較低的棋子攻擊價值較高的棋子（價值：車 9、炮 4.5、馬 4、相仕 2、兵 1）。
- 以下不算「捉」：帥（將）或兵（卒）發動的攻擊；被攻擊的是帥（將，該情況屬將軍）；被攻擊的是未過河的兵（卒）。

## 7. 和局
1. 雙方都沒有可過河攻擊的棋子（俥傌炮兵全無）→ 自動和局。
2. 連續 **120 步**（雙方各 60 回合）沒有吃子 → 自動和局（「60 回合自然限著」，可於設定調整）。
3. §6 判定的重複局面和局。
4. 雙方同意和棋。

## 8. 計時
- 超時方判負；但若對手只剩帥（將）與仕相，無任何攻擊子，則判和。

## 9. 記譜
- 機器格式：ICCS 座標（例 `h3e3`），與 Fairy-Stockfish／UCCI 相容。
- 顯示格式：台灣慣用中文記譜。紅方用中文數字「一～九」由紅方右側起算；黑方用全形阿拉伯數字「１～９」由黑方右側起算。例：炮二平五、馬８進７、前俥進三。
