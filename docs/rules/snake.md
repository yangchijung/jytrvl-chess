# JY Games 貪食蛇競技場（Snake Arena）規則 v1.0

引擎：`shared/snake/engine.ts`（確定性、固定步進；瀏覽器與伺服器共用）。單元測試：`tests/snake.test.ts`。

## 1. 地圖
- 單人標準：24×24；對戰依人數 30／38／46／52 見方。
- 地圖：開放、石柱、十字（中央留缺口）、四房（牆上留門）。
- 邊界：有牆（撞牆淘汰）或無牆（從另一側穿出，限單人模式）。對戰一律有牆。

## 2. 移動
- 每一步所有蛇同時前進一格；只能轉向，不能 180° 迴轉；最多預先排入 2 次轉向。
- 速度：慢 7、一般 10、快 14 步／秒；生存模式每吃 4 個食物加速 1 步／秒（最高 18）。線上對戰固定 10 步／秒。
- 同一步內尾巴先移開，蛇頭可以進入剛空出的尾巴格。

## 3. 食物與分數
| 物件 | 效果 |
|---|---|
| 紅色果子 | 長度 +1、+10 分 |
| 金色星星 | 長度 +3、+50 分，約 60 步後消失 |
| 淘汰對手 | +50 分（對手撞上你的身體，或正面相撞時你較長） |
| 生存模式 | 每 10 步存活 +1 分；每 50 步出現一個障礙物（不會出現在蛇頭正前方兩格） |

對戰中被淘汰的蛇，身體每隔一格變成食物。

## 4. 碰撞與淘汰
| 情況 | 結果 |
|---|---|
| 撞牆、障礙物 | 淘汰 |
| 撞到自己的身體 | 淘汰 |
| 撞到其他蛇的身體 | 淘汰，該蛇得到擊殺 |
| 兩個蛇頭進入同一格 | 較長者存活；一樣長同時淘汰 |
| 兩條蛇交換位置（頭撞頭身） | 雙方淘汰 |

## 5. 模式與勝負
| 模式 | 結束 |
|---|---|
| 經典 | 撞到就結束，比分數 |
| 生存 | 撞到就結束，比分數（時間＋食物） |
| 限時挑戰 | 2 分鐘；撞到扣 50 分並以長度 4 重新出發 |
| 電腦對戰／雙人同機／線上雙人／多人競技場 | 只剩一條蛇存活即勝；時間到時存活者中最長者勝（同長比分數，再相同為平手） |

## 6. 電腦 AI（只讀公開盤面）
- 簡單：直線距離追最近食物，12% 機率考慮危險方向、15% 判斷加雜訊。
- 中等：BFS 最短路徑吃食物，以可達空間檢查安全性（偶爾冒險）。
- 困難：BFS 路徑搜尋（優先自己比對手先到的食物）、時間感知空間預測（身體格會隨尾巴前進而空出）、避開較長對手蛇頭可能進入的格子、比對手長時攔截其前方格。

## 7. 線上公平性
- 伺服器（`SnakeRoom`）每 100 ms 前進一步，客戶端只送轉向；位置、食物、碰撞與勝負由伺服器計算。
- 斷線玩家由中等 AI 暫代；重新連線恢復控制。觀戰者可中途加入。
- 單人紀錄（標準設定：開放地圖、有牆、一般速度）由伺服器以簽章種子重播驗證，並檢查實際經過時間。
