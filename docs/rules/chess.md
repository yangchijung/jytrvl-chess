# JY Games 西洋棋規則 v1.0

採用 FIDE《Laws of Chess》（2023 年 1 月 1 日生效版本）第 1–9 條。走法產生、將軍、將死、王車易位、吃過路兵與升變由 chess.js（BSD-2-Clause）處理；和局判定由 `shared/games/chess/rules.ts` 依 FIDE 條文實作。

## 自動判定（系統直接結束對局）
| 情況 | FIDE 條文 |
|---|---|
| 將死 | 5.1.1 |
| 逼和（Stalemate） | 5.2.1 |
| 死局：雙方都不可能將死（子力不足） | 5.2.2 |
| 同一局面出現 5 次（Fivefold） | 9.6.1 |
| 75 回合無吃子、無兵移動（Seventy-five-move） | 9.6.2；最後一步若為將死，以將死為準 |
| 超時，但對手不可能將死 | 6.9 → 和局 |

## 需玩家申請（Claim）
| 情況 | FIDE 條文 |
|---|---|
| 同一局面出現 3 次（Threefold） | 9.2 |
| 50 回合無吃子、無兵移動（Fifty-move） | 9.3 |

輪走方可按「申請和棋」，伺服器驗證條件成立後判和；條件不成立則對局繼續。

## 協議和棋
任一方可提和，對方接受即和局（9.1）。

## 記譜
- 對局保存：FEN（起始局面）＋ UCI 著法序列；匯出／匯入 PGN。
- 顯示：SAN（例 Nf3、O-O、exd6 e.p.、e8=Q+）。

## 子力不足判定說明
採用 chess.js `isInsufficientMaterial()`：K vs K、K+B vs K、K+N vs K、雙方僅有同色格象。其他理論死局（例如完全封鎖的兵形）不自動判和，可協議和棋或依 75 回合規則結束。
