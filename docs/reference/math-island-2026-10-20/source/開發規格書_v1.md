# 數學遊樂島：國小 1–6 年級數學遊戲 開發規格書 v1

> 對象：國小 1–6 年級學生（主），家長與老師（輔）
> 平台：平板優先（iPad／Android 平板，橫直皆可），手機與桌機自適應
> 課綱依據：教育部《十二年國民基本教育課程綱要 數學領域》（108 課綱）四大主題：數與量（N）、空間與形狀（S）、關係（R，第二學習階段起）、資料與不確定性（D）。學習內容條目代碼（如 N-1-1）在正式開發前須逐條對照官方課綱原文校對，本文件的代碼與單元為規劃用，需教學顧問確認。
> 核心理念：邊玩邊學、邊學邊玩——每一關都是「一個數學概念 × 一種手感好的操作」。

## 2. 世界觀與包裝（商用質感）

- **世界觀**：「數學遊樂島」，六座島＝六個年級，每座島 4 個區域＝四大主題。孩子帶著吉祥物（建議：一隻會變形的小水獺「波波」）解任務修復島嶼。
- **美術風格**：溫暖扁平插畫＋柔和立體感（soft 3D shading），圓角 16–24px，大量留白；避免螢光高飽和與廉價漸層。
  - 主色：海島藍 #3A7BD5、珊瑚橘 #FF8A5B、嫩芽綠 #5CC28A、暖沙 #FFF4E3（背景）、深墨 #23303F（文字）
  - 年級島各有輔色，讓孩子一眼知道在哪一年級
- **字體**：標題「jf open 粉圓」或「源泉圓體」（需確認授權可商用），內文 Noto Sans TC；數字用等寬圓體，避免 1／7、6／9 混淆；低年級字級 ≥24pt。
- **聲音**：每個互動都有回饋音（放下、吸附、正確、錯誤要溫和不刺耳），背景音樂可關；全中文配音（低年級題目一律可朗讀）。
- **動態**：Lottie／Rive 製作角色與獎勵動畫；所有動畫 ≤400ms，不擋操作；支援「減少動態」設定。

## 3. 互動規範（平板點選＋拖曳）

### 3.1 觸控原則
- 觸控目標 ≥ 56×56 pt（低年級 64pt），彼此間距 ≥12pt
- 拖曳物件按下時放大 1.08 倍＋陰影，表示「拿起來了」
- 放置區有「吸附半徑」（物件中心距目標 ≤ 48pt 即吸附），降低小手精準度需求
- 放錯位置：物件彈回原位＋輕震動（Haptics），不扣分只計入嘗試次數
- 支援多點觸控防誤觸：同時只允許一個拖曳物件；手掌誤觸區（邊緣 24pt）忽略
- 每題都有「重來」按鈕；不使用長按與雙擊（低年級困難）

## 5. 程度與難度系統（自適應）

- **起點測驗**：首次進入每座島玩 8 題（約 3 分鐘）定位起始難度，不叫「考試」，包裝成「島嶼探險」。
- **三層難度**：
  - 入門：有教具、有圖示、數字小、無時限
  - 熟練：教具可收起、數字變大、混合題型
  - 挑戰：多步驟、文字應用題、可選限時
- **自適應規則**（v1 用規則式，v2 可換 BKT 知識追蹤）：
  - 連對 3 題：升一級數值範圍
  - 連錯 2 題：降一級並自動顯示教具
  - 單元精熟：近 3 次遊玩正確率 ≥85% 且平均作答時間低於該年級中位數
  - 間隔複習：精熟後第 1、3、7、14 天推送 2–3 題複習（每日任務）
- **錯誤類型標記**：每題選項設計「典型錯誤」（例如進位忘了加、分母相加），答錯時針對該錯誤給提示，並計入弱點報告。
- **三段式提示**：①重讀題目（朗讀）②給方向（「先算十位」）③用教具示範一步。用了提示仍可得星，但精熟判定打 8 折。

## 6. 獎勵與動機（不做成癮設計）

- 每關 1–3 星；星星可用來修復島嶼建築、裝扮吉祥物（純外觀，不影響學習）
- 每日任務 3 個（約 10 分鐘），完成即停，不設無限連玩誘因
- 不做抽卡／轉蛋、不做排行榜（低年級）；高年級可開「班級合作目標」
- 家長可設每日時間上限（預設 20 分鐘），到時吉祥物溫和提醒休息

## 7. 家長與老師端

- **家長儀表板**：本週遊玩時間、精熟單元、弱點概念（附「在家可以這樣陪練」一句建議）、週報推播
- **老師端（v2）**：建立班級、指派單元、全班熱力圖（哪個概念最多人錯）、課堂投影模式
- **帳號**：家長以 Email／Apple／Google 登入，孩子用頭像＋圖形密碼切換，孩子端不需 Email

## 8. 技術架構建議

| 層 | 建議 | 理由 |
|---|---|---|
| 遊戲端 | **方案 A（推薦）**：React + TypeScript + PixiJS（2D 渲染）＋ Rive 動畫，打包成 PWA，再用 Capacitor 上架 App Store／Google Play | 一套程式三平台；拖曳與動畫流暢；網頁工程師好維護 |
| | 方案 B：Unity 2D | 動畫物理更強，但包體大、Web 版較重 |
| | 方案 C：Flutter + Flame | 原生效能好，Web 次之 |
| 互動 | 自建 DragDrop 模組（Pointer Events，統一滑鼠／觸控／筆），含吸附、彈回、無障礙替代（點選 A 再點選 B 也能完成拖曳題） | 拖曳是核心體驗，不依賴第三方 |
| 題庫 | JSON 題目模板＋參數產生器（例：`{a: 10–99, b: 10–99, carry: true}`），每題自動驗算 | 無限題目、避免背答案 |
| 後端 | Cloudflare Workers + D1（與 JY-TRVL 同棧，可沿用經驗）或 Supabase | 便宜、全球節點、台灣延遲低 |
| 離線 | Service Worker 快取所有關卡資源，作答紀錄先存 IndexedDB 再同步 | 平板常在無網路環境 |
| 分析 | 自建事件表（answer_submitted、hint_used、level_complete）＋ PostHog | 支撐自適應與家長報告 |
| 音效 | Howler.js，預載＋音量分軌 | 行動裝置相容 |

## 附錄 A：獎勵與理財機制（James 2026-10-20 需求，總幹事草擬）
- 點數：玩遊戲得「島幣」。答對、精熟一個單元、每日任務各有不同點數；連續天數另有加成，但上限不高，避免刷題。

- 島幣銀行（理財概念）：
  - 活存：隨時可領，週利率 1%。
  - 定存：鎖 2 或 4 週，利率較高；提前解約就沒有利息。
  - 複利：每週日結算，畫成成長曲線給小孩看。
  - 存錢目標：小孩設定想換的獎勵，系統顯示還差多少、照目前存法要幾週。
- 投資（進階，三年級以上解鎖）：
  - 「果園」：買樹苗（低風險，穩定收成）。
  - 「漁船」：會遇到風浪（高報酬、有波動）。
  - 用來教風險與分散投資。報酬隨機但看得到機率，不連結任何真實股市。
- 數學連結：利息、百分比、比例、統計圖都出自真實的島幣數字，讓理財也是練習數學。
- 防沉迷與合規：沒有付費買點數、沒有抽獎，家長能看到所有交易紀錄，利率由家長設定。
- 家庭旅行基金（旅遊行程助理建議）：一種共同存錢目標，可以三個孩子一起存。存到門檻就能換下一趟旅行的決定權，例如挑一個景點、選一天的晚餐、在泳池多玩一小時；門檻和選項由家長設定。
- 存錢目標補充：家長設定大目標，孩子主畫面顯示進度條；定存到期的本息可設定自動轉入目標，以培養延遲享受。
