## 2. 領地爭奪戰 Territory Rush（v1.1 新增）

### 2.1 定位與原創性
- 網址：`/territory`（英文 `/en/territory`）；首頁同時展示四款遊戲。
- 即時圈地類型，**全部自行開發**：不使用 Paper.io 2 的程式碼、角色、美術、音效、受保護視覺設計或名稱。正式名稱為「領地爭奪戰／Territory Rush」。
- 不套用回合制棋類引擎；使用獨立的即時引擎與 Durable Object。共用會員、登入、排行榜頁、房間基礎設施（流量限制、房間代碼、邀請連結）、i18n 與設計系統。

### 2.2 核心玩法（詳見 `docs/rules/territory.md`）
- 角色持續移動，玩家只改變方向；有起始領地。
- 離開領地留下軌跡；回到領地時圈住的區域變成自己的領地（可奪取敵方領地）。
- 碰到軌跡會淘汰軌跡擁有者，可切斷對手軌跡攻擊；衝出邊界、正面相撞、領地被圈光也會淘汰。
- 即時顯示占地百分比與排行榜；勝負：最後存活、占地超過 60%、或時間到時占地最大者。

### 2.3 模式
單人 vs AI（1–7 個電腦）、雙人同機（可加電腦）、2 人線上、2–8 人線上、私人房間（房主可加入／移除電腦）、公開配對（滿 8 人、第 2 人加入 10 秒後或單人等待 20 秒後開局；人數不足以中等 AI 補到 4 人）、訪客遊玩、Google 登入。

### 2.4 電腦 AI
簡單／中等／困難三級，**只使用玩家看得到的資訊**（領地、軌跡、位置、方向），不讀取其他玩家尚未生效的輸入。難度差異以 `npm run ladder:territory` 量化驗證。

### 2.5 操作
桌機：WASD、方向鍵、滑鼠（往游標方向轉）；雙人同機：WASD 對方向鍵。手機：滑動或虛擬搖桿。客戶端以固定 tick 間內插渲染，轉向立即預覽。

### 2.6 視覺與回饋
平滑移動、彩色領地、圈地動畫、軌跡、即時占地百分比、排行榜、小地圖、淘汰通知、勝利／失敗動畫、音效開關、明亮／深色主題、JY Chess 品牌風格。繪圖採 Canvas 2D（評估 Phaser／PixiJS 後，因畫面以方格與簡單形狀為主，Canvas 2D 體積最小、無額外依賴即可穩定 60 fps）。

### 2.7 多人連線
- Durable Object `TerritoryRoom` 為唯一權威：10 Hz 固定 tick，伺服器計算位置、碰撞、圈地、淘汰與勝負；客戶端只傳方向。
- 每 tick 廣播差異（角色狀態、領地與軌跡變更、事件）；加入或重連時傳完整快照（RLE 壓縮）。
- 延遲補償：實體內插＋本地轉向預覽；斷線由自動駕駛暫代並可重連恢復；觀戰者可中途加入。
- 防作弊：無法偽造領地、速度或位置；輸入限速；偽造或不明訊息忽略；房主權限由伺服器檢查。
- 房間管理：大廳、房主、加電腦、開始、再來一局、閒置自動清除。

### 2.8 戰績與排行榜
獨立於棋類 Elo：場次、勝場、淘汰數、最大占有率、最高得分（最大領地格數＋淘汰數×50）。排行榜可依得分、勝場、淘汰數、占有率排序（至少 3 場）。列入條件：至少 2 位真人、對局 ≥ 30 秒或以淘汰結束；所有真人同一網路時不計勝場與淘汰數。

### 2.9 教學與語言
五步互動式教學（轉向、圈地、軌跡風險、切斷對手、勝負規則），以真實引擎執行、完成動作才進入下一步。介面、教學、結算、設定、排行榜皆有中英文。

### 2.10 交付項目
遊戲引擎、三級 AI、雙人對戰、多人即時連線、互動式教學、中英文介面、會員紀錄、排行榜、完整測試、正式部署。驗收結果見 `docs/ACCEPTANCE.md` §9。
