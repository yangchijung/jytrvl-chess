## 1. 範圍與交付定義

V1 目標一次包含 6 款遊戲，不以靜態 Demo 替代：

1. **Chess｜西洋棋**：FIDE 規則與三段 AI。
2. **Xiangqi｜中國象棋**：台灣慣用玩法；長將、長捉及重複局面需規則版本文件。
3. **Banqi｜台灣暗棋**：4×8、32 枚棋子、翻子與炮等特殊規則；需公開採用的地方規則版本。
4. **Territory Rush｜領地爭奪戰**：原創領地擴張、軌跡切斷與即時攻防；只參考一般玩法，不使用 Paper.io 2 的品牌或素材。
5. **Snake Arena｜貪食蛇競技場**：經典單人、計時、生存、AI、即時競技。
6. **Block Puzzle Battle｜方塊消除對戰**：原創落下方塊消行、連擊、障礙行攻防、單人及對戰；不使用 Tetris 商標或受保護素材。

語言只要**繁體中文（台灣）與英文**。包含桌機、手機、平板響應式設計；訪客與 Google 登入；個人戰績、分遊戲排行榜、私房邀請、公開配對。所有遊戲具規則教學、電腦 Easy/Medium/Hard、單人或練習、雙人同機與線上雙人；多人適用遊戲（Territory Rush、Snake Arena）提供 2–8 人競技。即時遊戲不得硬套棋類回合制引擎。

## 2. 通用體驗與模式細節

### 導覽

`/`：六遊戲入口與分類；`/chess`、`/xiangqi`、`/banqi`、`/territory`、`/snake`、`/blocks`：遊戲入口；`/learn/<game>`：互動教學；`/room/:id`：私人房間；`/matchmaking`、`/profile`、`/history`、`/leaderboard`、`/settings`、`/privacy`、`/terms`。語言網址策略由 Claude 提案，但必須有可分享的中英連結及正確 SEO 設定。

### 標準玩家流程

首頁 → 選遊戲 → 選模式（AI／本機／線上配對／私人房間／教學） → 選難度與局規（適用時） → 開始 → 對局結束與重玩／分享／分析。

### 公平性

- 正式真人計分局禁用 AI 提示或引擎教練。
- 排名以真人有效對局為準，各遊戲分別計算；不把單人或 AI 戰績納入相同積分池。
- 線上對局以伺服器為權威（合法走步、時鐘、勝負、碰撞、記分）。
- 暗棋未翻開棋子資訊只能存在伺服器，不能提前發至對手瀏覽器；暗棋 AI 亦不可偷看未知資訊。
- 斷線重連、悔棋需雙方同意（線上局）、認輸、和棋和逾時按局規處理。

## 3. 玩法規格與待鎖定決策

### 3.1 西洋棋

棋子合法移動、將軍／將死／逼和、王車易位、吃過路兵、升變、可請求與自動和棋（重複局面、50/75 步等），棋譜 FEN/PGN。評估 `chess.js` 規則及 Stockfish WebAssembly AI，注意 GPL 授權與部署方式。定義各難度時限／搜尋強度及實戰測試案例。

### 3.2 中國象棋

將帥、仕士、相象、車、馬、炮、兵卒、九宮、河界、塞象眼／蹩馬腿、將帥照面、將軍、將死／困斃。**必須固定並公布一套重複局面、長將、長捉規則與判例**，不以「台灣常見規則」這種模糊文字取代。評估 Pikafish 或替代引擎及其授權。

### 3.3 暗棋

4×8、32 枚棋子；隨機翻棋、公平的隨機種子／洗牌；第一次翻棋後陣營分配；相鄰移動與吃子；炮隔子吃棋；帥將與兵卒吃子例外。**上線前鎖定**炮能否非吃子移動、雙方停滯和棋、無合法著法、升降級吃子、時間與和棋條件，將採行規則列在遊戲中。AI 在資訊不完全條件下採啟發式、信念狀態／抽樣模擬。

### 3.4 領地爭奪戰

角色在自己領地內安全；離開後產生可被切斷的暴露軌跡；閉環返回領地可佔領；敵人觸碰暴露軌跡會淘汰持有者；以伺服器固定 tick 處理碰撞、圈地、勝負。待鎖定：世界尺寸、速度、轉向慣性、出生保護、單局時間、領地覆蓋衝突、淘汰後重生規則、排名計分。

### 3.5 貪食蛇競技場

經典單人（碰牆／碰自身）、Survival、Time Attack、2–8 人 Arena；吃食物變長、碰撞與淘汰；桌面 WASD／方向鍵、手機觸控轉向。待鎖定多人蛇頭相撞優先權、地圖大小、加速功能、重生與排行算法。

### 3.6 方塊消除對戰

經典落下拼塊、左右／旋轉／軟降／硬降、Hold、Next、Ghost、單行至多行消除、Combo、Back-to-Back、障礙行攻防。待鎖定：矩陣尺寸、方塊集合、旋轉／牆踢、落鎖延遲、垃圾行發送、計分規則、同時勝負處理。對局結果必須能重播與驗證。

## 4. 教學與遊戲內容（ChatGPT 負責）

每款至少提供五個互動關卡：①棋盤／目標 ②操作 ③進攻／吃子 ④特殊規則／風險 ⑤實戰任務。逐步引導、正誤回饋、上一關／重試／退出，兒童可讀的繁體中文及自然英文。教學要以實際規則引擎判定成功，不能只是文字或展示影片。對局後基本策略回饋須引用可追溯的棋步／數據；不允許生成沒有依據的分析。

ChatGPT 首批內容交付：每遊戲 onboarding 文字、規則說明中英版本、錯誤提示字典、遊戲說明卡、勝負提示及 5 個教學任務流程。內容需讓工程端以 i18n JSON／Markdown 匯入。

## 5. 美編與 UI 設計系統（ChatGPT 負責，Claude 實作）

**品牌：** `JY GAMES`；標語 `Play Together, Think Better.`。不更改 URL `chess.jytrvl.com`。

**設計方向：** 現代高質感家庭桌遊平台；有古典棋藝厚度但不仿古；可愛但不幼稚。棋類採克制的木質／暖白質感，即時遊戲採有辨識度的亮色軌跡與清晰速度感，整站由排版、按鈕、卡片、音效語彙統一。

**初版 Tokens（可依實際對比微調）：**
- Ink `#172B38`；Navy `#20364A`；Ivory `#F7F4EE`；Forest `#255C52`；Gold `#C4A66A`；Muted `#64727B`。
- 狀態色分辨成功、警告、錯誤，不只依賴色彩。
- 字體：繁中系統字型／Noto Sans TC 備援，英文字體 Inter／系統字型。
- 棋盤在手機上優先滿版但保留安全邊界，所有主要操作可單手觸及，觸控目標建議 ≥44×44 CSS px。
- 支援深色／淺色、降低動態效果、色弱友善、關閉音效，至少符合 WCAG 2.2 AA 目標。

**必要畫面：** 六遊戲首頁、模式選擇、AI 難度、各遊戲主畫面（桌面／手機）、教學互動、線上大廳與房間、等待對手、對局結果、排行、個人紀錄、登入／訪客、設定、連線失敗／重連。遊戲視覺用原創素材，避免第三方商業遊戲高度近似的介面與圖示。

**UI 驗收：** 360px 手機不橫向溢出；中英切換不截字；棋盤與控制層清楚；不能誤將遊戲狀態顯示為已同步；斷線、等待、重新配對都有明確狀態與操作。

## 6. 工程架構與營運（Claude 負責）

建議 React + TypeScript + Vite + Tailwind；獨立的六款遊戲模組；遊戲畫面依需求評估 Canvas／Phaser／PixiJS；Cloudflare Pages／Workers、Durable Objects + WebSocket、D1；Google OAuth。技術方案由 Claude 依當期官方文件與定價驗證後決定。

AI 本機運行優先評估 Worker／WASM；對戰權威邏輯不得把祕密狀態暴露給前端。所有套件、棋引擎、原創圖像／音效均需檢查授權，紀錄版本與來源。確保安全、頻率限制、成本警示、斷線復原、備份、監控、CI 測試與環境隔離。

**網域部署：**新建獨立 repo 與 Cloudflare 專案；不可修改 `jytrvl.com`、`planner.jytrvl.com`、`flight.jytrvl.com`、`riskctrl.jytrvl.com`。Pages CNAME 需以建立專案後真正的 `*.pages.dev` 目標為準；若 Workers Custom Domain 牽涉 Cloudflare DNS Zone，須先說明具體路由方案，不能只假設可在 GoDaddy 外部 DNS 以 CNAME 完成。DNS 由專案負責人設定。

## 7. 驗收條件（全部為正式版本範圍）

- 六款遊戲均完整可從開局至合法終局；每款三級 AI 具有可觀察棋力／決策差異。
- 六款遊戲均有本機雙人、雙人線上、規則教學；即時競技類的 2–8 人可連線。
- 主要瀏覽器及 iPhone、Android、iPad、桌機可操作；繁中／英文完整。
- Google 登入及訪客可用；戰績、排行可查；正式計分與練習資料隔離。
- 自動測試至少涵蓋規則極端情境、斷線／重新整理、同時輸入、錯誤與越權請求、暗棋祕密資訊、速度／位置作弊。

- 交付 repo、部署說明、DNS 確切值、授權清單、測試報告、維護文件、成本假設。
