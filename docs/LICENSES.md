## 6. How to re-check

```sh
npm ci
node -e 'const l=require("./package-lock.json"),p=require("./package.json");for(const s of ["dependencies","devDependencies"])for(const n in p[s])console.log(s,n,l.packages["node_modules/"+n].version,l.packages["node_modules/"+n].license)'
npm run build && ls dist/engines dist/engines/fsf
```
