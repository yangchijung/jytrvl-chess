# 色彩塗鴉樂 V1｜Claude 直接開工交接
日期：2026-10-18。產品決策已定；本文件是實作指令，不是等待核准的提案。

## 1. 方向與理由
讓 5–12 歲孩子一進來就能畫，透過「猜顏色 → 混一混 → 畫出來 → 比較 → 再試」練習觀察推理與視覺表達。這是學習設計目標，不宣稱已證實提升智力。畫紙為主角，以動作及結果教學，每次只顯示一個短指令；不把色彩學做成閱讀問卷。

先讀根目錄 DESIGN.md、AGENTS.md、STATE.md。餐廳繼續暫停。沿用已上線 React／TypeScript 平台，不重做登入、DNS、其他七款規則引擎。

## 2. 首次使用及畫面
名稱：色彩塗鴉樂／Color Doodle。預覽路由 /doodle 與 /en/doodle。
首次進入直接顯示空白畫紙，主要動作「畫畫看」；旁邊次要入口「玩混色」。不用帳號、生日或分級測驗。自由畫不需先過關。

- 直式手機：共用頁首 → 畫紙 → 畫筆／色盤 → 操作列；工具分組可換行，不用水平捲動找按鈕。
- 平板／桌機：畫紙佔主要空間，右側放色盤及混色盤；底部一行短提示。
- 可見主工具最多五類：畫筆、橡皮擦、蓋印章、顏色、復原；筆粗僅細／中／粗，預設中。重做、儲存圖片、換新紙放次要工具列，均可用鍵盤。
- 首次提供三原色及白色；混出的橙、綠、紫直接出現在色盤。自由畫可隨時展開完整色盤，沒有付費或過關鎖。
- 圖示配 2–4 字標籤，不只用 emoji。繪畫操作目標以 48×48 CSS px 為主，所有一般控制至少 44×44。
- 預設「輕鬆玩」（適合 5–7 歲）：一次一個動作、色塊大、只顯示目前需要的工具；可切「多試一點」（適合 8–12 歲），加入預測及配色比較。任何人可切換，不記錄年齡。
- 任務成功回饋在混色盤／畫紙上出現，120–220ms；關閉動畫時立即顯示結果。沒有閃爍、粒子慶祝或強迫倒數。
- 每步主提示繁中原則不超過 12 字。詳細說明放「為什麼」按鈕；讀屏名稱不能因短文案省掉必要語意。語音是後續加值，不是首版依賴。

## 3. 可玩的核心
1. 點色塊後自由畫；支援手指、滑鼠、觸控筆，畫筆位置正確。
2. 混色盤放兩個等量色點，點「混一混」，顯示混色前後及結果色名，點結果直接畫。
3. 六個短任務見同目錄 doodle-lessons-v1.json；可跳過、重試、回自由畫，沒有扣分／淘汰／連勝壓力。
4. 復原／重做以一整筆或一枚印章為一個操作。清紙前確認，取消保留畫作；確認後仍可復原最近一次清紙。
5. 本機保存自由畫與格子模式各一張畫紙及任務進度，重新整理／旋轉裝置不丟圖。存檔成功後才顯示「已存好」；容量不足或停用儲存時保留當前畫面並提供下載。
6. 匯出 PNG，與畫紙同色、不含 UI；不要求照片權限。檔名可固定時間格式，無姓名。V1 不含上傳、公開作品牆、聊天、付費素材或雲端 AI 評分。

## 4. 色彩教學的正確邊界
V1 使用「簡化顏料混色」：紅＋黃→橙，黃＋藍→綠，藍＋紅→紫。這是傳統 RYB 教學模型，真實顏料因材料、比例不同會有差異；不是螢幕 RGB 加法，也不是精確顏料模擬。

工程以 JSON 固定配方查表，輸入順序可交換，不能直接將兩個 sRGB hex 做平均或拿 Three.Color.lerp 當顏料物理。V1 只做三組等量混色及指定加白階段，不開放任意多色連混／任意比例後硬猜結果。自由繪畫的透明疊色屬繪畫效果，不能當任務答案或聲稱模擬真實顏料。

色票是經選定的螢幕示意值；所有任務以 color ID 判斷，不以相機、像素相似度或孩子畫得像不像評分。
- 加白示意用指定色票，教「變亮」，不混稱更飽和。
- 暖／冷是常用配色分類，不強迫顏色代表固定情緒。
- 互補任務限明示的 RYB 教學色環及黃／紫對，不混用 RGB 色環對向色。
- 詳細說明一句：「這裡模擬顏料；真實顏料混色會有差異。」英文："This simulates paint. Real pigments may mix differently."

資料依據：[Adobe 色彩模式](https://helpx.adobe.com/creative-cloud/apps/colors/understand-color-modes.html)、[Adobe 傳統色彩混合](https://www.adobe.com/creativecloud/design/discover/secondary-colors.html)。查閱日期 2026-10-18。

## 5. 美術與 Three.js 決策
UI 沿用 DESIGN.md 的實色紙白／墨色／森林綠，警示另計；色盤、混色結果及孩子作品的多色是遊戲內容，不能拿來裝飾導覽或做漸層背景。作品保有原色，深色主題只換工具與周邊；畫紙預設仍白色。

美術用 Figma 製作原創畫筆／混色盤／印章圖形，或負責人已允許的 Canva、Higgsfield、Adobe。首版先用可辨識的基本圖形與既有圖示跑通玩法，不等完整素材包。成品素材補來源、製作方式與授權紀錄，不引入付費產圖依賴。

**Claude 可以使用 Three.js；最快交付的預設是 Canvas 2D 畫紙＋DOM 工具。** 若已有可重用 Three.js 工作方式，可用正交相機做 2.5D 畫桌或混色動畫；功能界面仍是 DOM。不要把三維化或七款全面遷移列為前置工作。
- Three.js 僅由新路由延遲載入；無 WebGL 或 context lost 時保留 Canvas 繪畫與保存。
- 輸入及輸出維持正確 sRGB 色彩管理；任務顏色避免受場景燈光、tone mapping 改變。官方參考：[Color management](https://threejs.org/manual/pages/color-management.html)、[OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html)。
- Canvas 像素密度上限預設 2，尺寸改變時用可重播筆畫重繪；不要在旋轉時清空。
- 只在繪畫區設定需要的 touch-action；離開畫紙仍能捲動頁面。處理 pointer capture／pointercancel／第二根手指、快速離開畫紙，不留黏住的線。
- 筆畫用畫紙正規化座標並保留寬高比例；小尺寸不能截掉畫作。筆畫資料含 schemaVersion；讀取失敗不得靜默覆寫舊資料。

## 6. 無障礙及孩子可用性
色塊同時有名稱、形狀／記號及選取狀態，不能只靠色差。工具為真實按鈕，選取工具使用可讀的 pressed／selected 語意；混色完成用單一 polite 訊息讀出，例如「紅色加黃色，變成橙色」。不能每移動一個筆點朗讀。

自由手繪本身無法靠補一個 aria-label 就宣告讀屏可用。另提供「格子蓋印章」：3×3 大格、顏色＋圓／三角／方形，方向鍵移動、Enter 蓋章，每格讀出位置及內容，VoiceOver 可逐格啟動。六任務可用混色按鈕及印章完成，無需精確拖曳。格子模式與自由畫各保留自己的畫紙，切換不能丟資料。

400% 下工具可以垂直排，不因固定頁首遮住焦點；畫紙是需要二維操作的內容，不把整個工具列都當作豁免。尊重既有減少動態設定及系統設定，保留可見焦點、清紙取消／確認後的焦點回復。
