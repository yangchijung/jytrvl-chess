## 2. 設計方向與頁面結構

孩子的任務是「看見數量 → 動手擺放 → 看懂結果」。主操作是場景中的物件與目的地；先讓孩子動手，不要求閱讀說明書或開帳本。

資訊層次：立即看到一幅場景、一句短任務及「聽一遍／重來」；完成後才出現下一題；玩法詳解、課綱、家長資訊放次層。水獺波波只負責示範與具體回饋，不長篇說教。

| 路徑 | 本批內容 | 主要操作 |
|---|---|---|
| /math | 簡單島圖；只露出已可玩的蘋果籃、分裝工廠 | 選遊戲／接著玩 |
| /math/g1/apple | 一年級：兩堆合成、數量與算式 | 把蘋果移入籃子，再選總數 |
| /math/g3/factory | 三年級：等分、除法意義 | 分到每個盒子一樣多，再選每盒數量 |
| /math/g1/fish、/math/g1/order | M1 才開：數量、數序 | M0 不放不能玩的假入口 |
| /math/g3/parking、/math/g3/pizza | M1 才開：位值、同分母分數 | M0 不用「即將推出」卡片塞滿島圖 |
| /math/parent、/math/bank | 附錄已讀；家長驗證及交易規則定案後再排程 | M0 不接實際獎勵或交易 |

沿用現站語言路由機制，M0 先提供繁中題目與國語示例語音作試玩基準，這不是取代 #28「正式語言待 James 決定」。若共用切語言會進 /en/math，英文外框應明示試玩題目目前為繁中，不可 404 或假稱已有英語題庫。正式雙語題目／音軌待決。

「小魚數數」是獨立數學遊戲，與色彩塗鴉「我的小魚」分開路由、技能與存檔，不能混用進度。

新專區先 noindex 預覽、不改正式首頁遊戲數；PR 預覽網址足以讓家庭試玩。正式導覽入口／首頁接線另列可驗收增量。

### 與 DESIGN.md 一致的落地方式

- 固定暖沙 #FFF4E3、深墨 #23303F、海島藍 #3A7BD5 三個核心色，珊瑚橘僅作語意提示。其餘草案色票留素材參考，不在同一介面全數堆上；主按鈕深墨底暖沙字，其他組合逐一驗對比。
- 圖畫是題目中的可數物件、等分模型與放置目標，不以裝飾圖卡取代可玩的場景。波波採原創 AI 插畫後人工修整；正式素材附來源、工具與人工檢查紀錄。暫用幾何圖形時清楚列未完成素材，不用 emoji 冒充成品。
- 拿起可等比放大 1.08 並加輪廓；不加裝飾陰影。放錯平順回原位，120–220ms，無彈跳、搖晃或責備文案；減少動態時直接定位。輕震動僅能力可用且未關閉時輔助，不是 Safari 必須成功的通關條件。
- 一般控制至少 56、低年級操作至少 64 邏輯點；間距採 16 邏輯點。交接中的 48pt 吸附半徑，在網頁按 iPad 邏輯座標以 **48 CSS px** 表示，不能乘上 DPR，也不能寫成 CSS 48pt。低年級主要題字至少 32 CSS px（24 CSS pt），支援放大。
- 地圖／遊戲主畫面避免長文字、過大圓角、膠囊資料、漸層、排行榜與連續登入獎勵。對錯同時用形狀、位置、短語音／文字表達。

## 3. M0 兩款可玩切片

每款：1 個直接在場景內的操作示範＋5 題固定順序＋完成回饋。兩款可直接選，不要求一年級先通過才能看三年級；標示學習內容，不以年齡強制鎖關。M0 固定題是驗證玩法，不等於正式題庫完成。

### 蘋果籃

- 固定題：3＋4＝7、2＋3＝5、4＋1＝5、1＋2＝3、4＋4＝8。畫面先呈現兩堆蘋果；搬進同一籃子後仍能看出來源兩組，數量守恆。這延續已交接 M0 的合成情境；原型「籃內已有 3 再添加 4」保留後續獨立題型，不混用題目敘述。
- 短提示：「把蘋果放一起」「一共有幾顆？」；重聽、拿回／重來可用。正確：「3 加 4，一共 7 顆。」
- 三個答案選項必須相異、合法、僅一個正解；錯答保留操作成果並提示可再數一次，不扣分、不退關。
- 一個物件只能在一個位置；連點、取消拖曳、旋轉、重整都不能變多／消失。未搬完時仍可探索，判答前提示先把兩組合好，不代替孩子直接填答案。

### 分裝工廠

- 固定題：12 個分 3 盒，每盒 4；18 個分 3 盒，每盒 6；8 個分 2 盒，每盒 4；10 個分 2 盒，每盒 5；15 個分 3 盒，每盒 5。此批只做等分整除。
- 短提示：「每盒放一樣多」「每盒有幾個？」；物件可以移回來源或盒間搬動，不預先標答案。
- 先檢查總數是否全分完、各盒是否一樣多，再接受每盒數量；例如 12 分成 5／4／3 不得因總數正確就通過。
- 正確後才顯示圖像對應算式 12 ÷ 3 ＝ 4；說明「3 盒，每盒 4 個，一共 12 個」。
- 三年級後續再加入分裝與餘數；M0 不混在同一題問「幾盒」與「每盒幾個」。

### 共用操作契約

拖曳與「先點物件、再點目的地」效果完全一致；鍵盤選取／放置也經同一動作規則。吸附採放手時物件中心到合法目標區域的最近距離 ≤48 CSS px；區域內距離為 0。多目標候選取最近者，相等且有歧義則保留選取、要求點選目標，不隨機放置。此規則只幫定位，不透露數學正解；教學可容許的放置照收，判答另做。

只追蹤第一根手指；第二根不搶物件。pointercancel、離頁、旋轉或縮放中斷時回到最後一次已提交位置，不重複計數；保留瀏覽器縮放，不全頁禁止手勢。縮放、捲動後以實際場景座標換算，測 47／48／49 px 邊界。

下表是產品端依官方課綱原文所作對應，**不是教學顧問已審查通過**。實作題型都需記錄技能 ID、參數界線與來源頁碼。可按準備度調整，不依學校週進度。

|---|---|---|---|
| G1-1 | 小魚數數：一物一數、數量 | N-1-1 | 先 1–5，再 0–10／20；不用追逐魚考反應 |
| G1-2 | 蘋果籃：合併與拿走 | N-1-2／N-1-3、R-1-1 | M0 只加法；M1 加 0 與減法，沒有負數／未知加數 |
| G1-3 | 排排站：數序 | N-1-1 | 先 0–10 的 3–5 張卡排序；不要求背大小符號 |

## 5. 朗讀、保存與資料範圍

- 沿用已拍板 Azure Neural TTS 預先產音檔，前端只播快取檔；題目、數字、加減除與停頓須逐句試聽。金鑰是服務端環境 secret，不進 repo／前端 bundle；素材表列出文字、locale、voice、檔名與版本。[Azure 批次合成文件](https://learn.microsoft.com/azure/ai-services/speech-service/batch-synthesis)
- 預設朗讀開啟，在孩子第一次按「開始玩」後啟動；重整後若瀏覽器阻擋，顯示「聽一遍」明確按鈕。停止／靜音立刻生效；換題終止上一題，不疊音。缺音檔仍能玩且可重試。這符合瀏覽器可能要求使用者先互動的限制。[MDN 自動播放說明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)
- 國語為 M0 暫定試玩基準；正式國語／英語／雙語待 James 決定，不批次製作尚未確認的整套音軌。TTS 權限或音檔未到位不能標朗讀驗收完成。
- M0 不建立孩子真名、Email、生日或正式帳號，使用匿名單機試玩狀態；本機重整可續同題。這不替代正式進度本機／跨裝置選擇。
- 存檔至少包含版本、遊戲／題目 ID、已提交物件位置、完成狀態與朗讀偏好；動作提交後保存，動畫不驅動數學結果。壞檔保留原文、寫失敗不稱已存好；新舊版本與多分頁策略須明定，採交易式保存或可驗證單寫入者，不能沿用餐廳兩次讀取就宣稱原子安全。
- 不串廣告、第三方追蹤、付款、付費點數與抽獎。M0 無可兌換島幣、銀行、投資或家長核准假流程；完成回饋保留在學習成果。
