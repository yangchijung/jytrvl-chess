## 1. 已確定的方向

負責人指定：「下一套，數獨。開始設計，用經典模式。」因此數獨取代五子棋，成為下一款優先開發的遊戲。以下操作、難度與驗收細節由 ChatGPT 產品端提出並定稿為首版基準；不是負責人逐項指定。Claude 可直接依此拆解實作，遇到技術限制需附替代方案。

- 名稱：經典數獨／Classic Sudoku；首頁名稱：數獨／Sudoku。
- 單人 9×9，簡單、中等、困難三種難度；先選「簡單」。不用登入即可玩。
- 核心循環：選難度 → 開始 → 填答／筆記／取得邏輯提示 → 完成 → 再玩一題。
- 首版含：復原、清除、手動筆記、暫停、重新開始、本機自動保存與續玩、規則教學、中英文、深淺色。
- 沒有生命數或三次犯錯淘汰，也不因耗時強制結束。
- 首版不含每日題、限時賽、多人房間、對戰 AI、公開排行榜、帳號跨裝置同步與分享成績圖。這些是後續範圍，不能阻塞經典模式。

既有平台的「三級 AI／多人房間」要求不套到數獨。數獨的提示是可驗證的邏輯引擎，不需要語言模型或外部生成服務。

## 2. 經典規則與題目契約

81 格分成 9 列（橫向）、9 行（直向）、9 個 3×3 宮。完成時，每列、每行及每宮都恰有 1–9 各一次。題目數字固定，不可改寫；玩家只能改空格的填答。候選筆記不算填答。

每道上架題必須有且只有一個解。唯一解驗證與難度評級是兩個獨立條件：回溯搜尋可用來驗證唯一解，但不得以搜尋步數或挖空數直接命名難度。

| 難度 | 解題引擎允許的技巧上限 | 分級門檻 |
|---|---|---|
| 簡單 Easy | 單一候選（naked single）、唯一位置（hidden single） | 僅靠這兩種技巧可完整解出 |
| 中等 Medium | 再加入宮列／宮行排除（locked candidates，含 pointing／claiming）、裸對（naked pair） | 簡單引擎停住；中等引擎可完整解出 |
| 困難 Hard | 再加入隱性對（hidden pair）、X-Wing | 中等引擎停住；困難引擎可完整解出 |

各級是 JY 自訂、可重現的難度標準，不宣稱等同其他數獨 App。實作固定技巧優先序、列／行／宮及格子掃描順序，保存邏輯步驟；以最低可完整解出的級別分類。需要猜測、搜尋分支或超出技巧的題不進首版題庫。不能為湊題量把簡單題標成困難。

首版建議隨程式附帶離線預驗證題庫，至少每級 30 題且 givens 不重複；優先提供最近 10 題之外的題。開局不等待線上產題。Claude 可改用本機生成，但仍須具備已驗證的備用題庫、可重現 ID 與時間上限，不能讓玩家無限等待。

題目資料至少有：`puzzleId`、`rulesVersion=classic-1`、`difficultyVersion=logic-1`、`difficulty`、81 位 `givens`、解答、生成／來源紀錄及驗證摘要。題目與題庫工具自製，或記錄可用的來源授權。附件樣題為本輪自建設計測試資料，只有一題，不能充當正式題庫。

## 3. 視覺與頁面

沿用 JY 現有紙白、墨綠、少量金色及字型；不發起全站改版。接現有 CSS token：`--bg`、`--surface`、`--text`、`--muted`、`--accent-text`、`--accent-fill`、`--accent-soft`、`--err-text`、`--err-bg`。深色實心主按鈕用現有 `--accent-fill`，不是較亮的文字綠。

### 入口

- 新增「益智」分類遊戲卡，短文案：「在 9×9 方格中，找出每個數字的位置。」
- 建議路由：`/sudoku`、`/en/sudoku`；教學 `/learn/sudoku`、`/en/learn/sudoku`。沿用語言、theme、canonical 與 hreflang 機制。
- 沒有存檔：顯示三種難度及「開始遊戲」。有有效未完成存檔：主要按鈕「繼續遊戲」，次要「新遊戲」。

### 進行中

手機由上而下：名稱與難度／計時 → 棋盤 → 放大九宮與暫停 → 選格位置 → 復原、清除、筆記、提示 → 數字鍵盤 → 提示說明（需要時展開）。新遊戲、重新開始、規則可放在「更多」選單；主要填答操作不藏選單。

桌機以棋盤為主，右欄放選格位置、工具、數字鍵盤、提示。棋盤建議 396–468 px；手機依可用寬度等比顯示，不橫向溢出。數字鍵盤手機為 5＋4 排、每鍵至少 44×44 px；清除獨立列於工具列，不放假的第十個數字。互動預覽為節省範圍把重新開始放在數字鍵旁，正式版依本節用更多選單。

| 元素 | 呈現 |
|---|---|
| 題目數字 | 主文字色、較粗字重；讀屏標記「題目」 |
| 玩家填答 | 墨綠／深色用亮綠，細底線；讀屏標記「填答」 |
| 候選筆記 | 格內固定 3×3 位置，數字依 1–9 排列，不以緊縮字串擠在角落 |
| 選中格 | 淡綠底＋明確內框；上方顯示第幾列、第幾行 |
| 同列／行／宮 | 低強度背景，不能淹沒選中格 |
| 相同數字 | 柔和綠底；僅視覺輔助，不改答案 |
| 重複衝突 | 錯誤底色＋「!」與可讀文字；同一衝突的相關格都標示 |
| 3×3 分隔 | 比細格線清楚；九宮邊界在深淺色皆可辨識 |

不靠顏色單獨傳達題目／填答／錯誤；一般文字對比至少 4.5:1，必要非文字控制與邊界 3:1。驗收量測實際組合，不能只比 token 原始色。

### 手機選格與放大九宮

360 px 螢幕扣邊距後，每格約 35–36 px，不可能同時容納 9×9 個 44 px 格子。**本次產品決策補充既有 44 px 規則**：完整棋盤是密集資訊選格區，允許小於 44 px；點格只移動選擇，不直接填值。填入必須透過至少 44 px 的數字鍵或鍵盤，不能擴張成互相重疊的 hit area。

必須同時提供「放大九宮」：把選中格所在 3×3 宮放大，九格皆至少 44 px，保留全域列／行座標，提供 1–9 宮的選擇控制；按「完整棋盤」回復。筆記太小看不清楚時同樣可用。選擇其他宮不改答案、不清筆記；跨宮鍵盤移動同步切換。非棋盤互動目標仍維持 ≥44×44 px。這是明示的產品取捨，不是宣稱 360 px 完整棋盤的每格都已達 44 px。

## 4. 操作契約

1. 點格只選擇。點題目可觀察相關格，但輸入、清除不改題目，顯示短說明。
2. 填答模式下點 1–9 會填入或取代所選空格的既有填答；再點相同數字是無操作，不當作清除。
3. 筆記預設關閉。開啟後點數字切換該候選；只可對沒有填答的格使用，已填格提示「先清除填答」。筆記不驗成答案。
4. 填入數字時，清除此格筆記，並從同列／行／宮其他格的筆記移除該數字。這整批為一個復原動作。清除或取代舊數字，不自動猜測應補回哪些筆記；復原可精確還原。
5. 清除刪掉所選格的填答與筆記，空格無內容時無操作。不能清題目。
6. 復原依序撤銷填入、取代、筆記及清除，包含自動移除的筆記；至少保留本局最近 100 個動作，重整後仍可復原。選格、暫停不加入歷史。不必做重做。
7. 筆記開關要同時有文字「筆記：開／關」與按下狀態；切回填答的狀態不可只用顏色提示。
8. 鍵盤：方向鍵移動不繞邊；1–9 填答／筆記；Delete／Backspace 清除；N 切筆記；Ctrl／Cmd+Z 復原。僅在遊戲焦點範圍攔截，對選單、輸入框及瀏覽器快捷鍵不全面攔截。原生按鈕有焦點樣式。

正式版採可讀屏的 grid／row／gridcell 結構與單一棋盤 Tab 入口（roving focus），方向鍵在棋盤移動；格子名稱包含列、行、數字、題目／填答／筆記、衝突。暫停或對話框開啟後焦點移入，關閉回原觸發處。預覽的 81 個原生按鈕用於確認互動，不能代替正式無障礙驗收。

## 5. 衝突、完成與提示

即時檢查只檢查「同列／行／宮是否重複」，不在每次輸入偷偷對答案報錯。錯誤可保留並更正，不扣生命。沒有紅字也不等於已填對。81 格填滿時，重新驗證全部規則及固定題目；全通過才完成。筆記不能觸發完成。

提示不是隨機揭答案，流程如下：

1. 若有明顯重複，先指向重複區並請玩家修正；此純規則提醒不增加提示次數。
2. 取得當前填答可延伸的解；若無解，指出一個造成矛盾的玩家填答（可利用唯一解核對），說明「這格的填答使題目無法完成」，不自動改答案。這是額外協助，計 1 次提示。
3. 有解時，以允許技巧找可驗證下一步；候選從題目與當前填答重算，不依賴玩家可能不完整的筆記。先選中相關格並高亮支持證據，再顯示技巧與自然語句理由。
4. 有可填數字時，顯示「幫我填入」；只有點下才填。排除型技巧顯示「套用候選排除」，以正式記錄的候選／筆記交易處理，不假裝直接得到答案。說明必須指出哪幾格、哪幾個數字及哪個列／行／宮。
5. 邏輯引擎應可接續前次提示的有效排除結果，並在玩家改值後重新推導；不能每次提示都重複同一排除步驟。對玩家筆記的顯示更新和內部證明分開管理。
6. 每個新提示步驟在說明揭露時計次；同一步驟面板的展開／關閉或「幫我填入」不再加一次。復原、重整不消除本局「使用過提示」標記或減少次數。不能藉先看提示再取消得到無提示紀錄。
7. 若引擎沒有下一步，顯示可重試的短訊息，保留局面並留下可重現工程證據；禁止默默退回不解釋的答案揭露。正式題庫測試必須排除此情形。

範例：「看看第 2 列、第 7 行，以及所在的九宮。排除已出現的數字後，這一格只剩 4 可以填。」附件樣題可驗證此步；完整首版提示要涵蓋三個難度的所有允許技巧。

## 6. 暫停、保存與完成頁

### 計時與保存

- 按開始／繼續才計時；載入入口不計時。用單調時鐘累積活躍秒數，不能只靠每秒 callback 次數。計時無上限；超過一小時顯示時分秒。
- 手動暫停、頁面背景化、離開遊戲、重整均保存並暫停。棋盤、筆記、提示全部遮住；回頁面需按繼續，避免人在背景但計時失控。完成停表。
- 自動保存每個有效動作及暫停／離開事件；本機一份進行中存檔。至少保存題目 ID／版本、givens、填答、筆記、動作歷史、提示／排除記錄、activeElapsedMs、難度、開始時間及存檔 schemaVersion。不要每秒同步網路。
- 保存成功顯示「已儲存在此瀏覽器」，不是「雲端同步」。切換語言不產生第二份存檔。登出不清除本機單人局；跨裝置不同步。
- 本機儲存被封鎖／容量不足：繼續可玩但明示「無法儲存，離開後可能遺失進度」。損壞或不支援的版本：不能靜默清除；保留原資料，顯示無法讀取與「開始新遊戲」選項。
- 多分頁只容許一個分頁寫同一局；其他分頁進入暫停並說明「這一局已在另一個分頁開啟」。用 session revision／寫入者識別處理，不用最後寫入默默覆蓋。

### 新遊戲與重新開始

有進度時，新遊戲顯示確認及難度選擇；取消完全保留原局。確定後才更換題目、歸零時間與提示次數。重新開始是同一題、清空填答／筆記、重計時間；其完成紀錄標記為「重玩」，避免被當成首次獨立解出。原局使用過提示的事實保留在歷史紀錄，不回寫刪除。

### 完成頁

顯示「完成了！」、難度、遊玩時間、提示次數，以及「未使用提示／使用過提示」；重玩另有標記。主要動作「再玩一題」（同難度新題），次要「查看棋盤」「返回大廳」。可展開完成棋盤，但不可繼續改答案或重複寫入完成事件。

僅保留最近 30 次本機完成紀錄，按遊戲 session ID 去重；無全站分數、無 Elo、無公開最速榜。清楚說明紀錄只在此瀏覽器。這種時間紀錄不具防作弊保證；未來若新增正式排行榜，需另訂驗證與計時規格。

## 7. 教學與文案

規則教學為可重開的短流程，不擋住一般遊玩：①每列 1–9 ②每行 1–9 ③每宮 1–9 ④一格只剩一個候選 ⑤筆記與提示。用原創小範例；需玩家實際填一次、切一次筆記，成功後再前進。不做對戰 AI 教練。

雙語字串包：[sudoku-copy-v1.json](../handoff/sudoku-copy-v1.json)。工程依既有 i18n key 結構整合，不另建翻譯系統。英文中 row=列、column=行、box=宮，避免翻譯時互換。

互動設計稿：[sudoku-classic-preview.html](../design/sudoku-classic-preview.html)；以 HTML fragment 交付，可放進本機預覽容器，沒有網路請求。它展示一題簡單樣題、選格、填答、筆記、清除、復原、提示、暫停及放大九宮。它沒有完整三難度題庫、正式存檔／多分頁協調、教學或完整難度提示，**不可直接當正式遊戲部署**。正式行為以本文件為準。

樣題：[sudoku-classic-fixture.json](../design/sudoku-classic-fixture.json)。本輪以獨立回溯驗證唯一解，並驗證 45 步單一候選／唯一位置邏輯可以完成；這項驗證只涵蓋樣題，不等於正式數獨測試已通過。

## 9. 驗收清單

| ID | 情境 | 通過條件 |
|---|---|---|
| SU01 | 題庫 | 每級至少 30 個不同 givens；每題尺寸／固定數字合法，解數=1；0 解／多解／損壞題被拒絕 |
| SU02 | 分級 | 每題按最低可解引擎分級；trace 可重播到完成；中等不能被簡單解完、困難不能被中等解完；不靠挖空數分級 |
| SU03 | 題目保護 | 滑鼠、觸控、鍵盤、清除、復原皆不能修改 givens |
| SU04 | 填答與衝突 | 列／行／宮重複正確標示；僅非重複但答案不符的填答不即時揭答案；沒有生命數 |
| SU05 | 筆記 | 固定九格位置；筆記不算填答；同區自動移除和復原一致，無關區不受影響 |
| SU06 | 復原 | 填入／取代／筆記／清除各一個交易；100 步保留；重整後可回復；不退還提示次數 |
