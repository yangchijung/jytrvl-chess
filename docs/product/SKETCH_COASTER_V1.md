# 手繪雲霄飛車（Sketch Coaster）規格 v1

來源：James 2026-10-21 交付（原文照錄），同日指示「一樣部署在 Game 裡面」。實作：`public/coaster/index.html`（單一檔案，網址 /coaster/）。

指令：從零重寫一個「手繪雲霄飛車」網頁（參考 rakugaki-coaster 的架構）
請用單一 index.html（原生 HTML/CSS/JS，不用框架、不用 Three.js）做一個網頁小遊戲：使用者用手指或滑鼠在畫面上畫一條線，放開後這條線變成雲霄飛車軌道，按「出發」後以第一人稱 3D 視角乘坐，結束後可分享連結讓別人搭同一條軌道。程式碼與美術請全部原創，不要複製原網站的程式或素材。

1. 畫面結構
三個 canvas 疊放：#cv（2D 繪圖與側視圖）、#gl（WebGL 第一人稱）、#mini（乘坐時右下角小地圖，M 鍵切換，狀態存 localStorage）
狀態機 mode：draw → drawing → ready → ride → done；開分享連結時為 shared
世界座標用公尺，PX_PER_M = 10；地面固定在畫面底部上方 76px；devicePixelRatio 上限 2
語系：?lang=ja|en，沒帶參數就看 navigator.language；文字集中在一個字典物件
2. 手繪輸入
Pointer Events＋setPointerCapture；pointermove 用 getCoalescedEvents() 拿到高頻點
新點距離上一點 ≥0.2m 才記錄；點不能低於地面上 1.2m
總長 <25m 就提示「太短」並重畫
3. 線條平滑（關鍵演算法）
每 0.25m 重新取樣，再做 5 點移動平均去除像素抖動
不直接平滑座標，而是平滑「行進方向角度」：算每段 atan2 角度（做 unwrap 避免 ±π 跳動），用高斯模糊（σ≈2m）後再積分回座標。這樣手抖會消失，但畫的圈圈仍然是同樣大小的圈
積分後的形狀會偏移，用更寬的高斯（σ≈6m）把「原始點 − 新點」的誤差慢慢拉回去
每 1m 重新取樣一次，成為控制點
4. 分享碼（網址 hash）
格式：第一個控制點當原點，存地面高度差（int16，2 bytes），之後每點存與前一點的 dx、dy（公分，int8，限制 ±127）
Uint8Array → base64url（+→-、/→_、去掉 =），放在 #t=...
開啟連結時解碼，自動縮放鏡頭（fitView）讓整條軌道入鏡
畫的人和開連結的人都要搭「解碼後」的同一條軌道，確保結果一致
5. 軌道幾何
Catmull-Rom 樣條穿過控制點，每段細分 8 份，再依弧長每 0.25m 重新取樣
每點算單位切線 (tx, ty) 與曲率向量（用 ±6 點的二階差分，再做 11 點平均，避免手繪造成 G 力尖峰）
決定車子在軌道哪一側（sigma），讓出發時是正的，之後固定不變，所以畫圈時會倒過來
前後各延伸 30m 的平直段當車站
6. 物理（固定時間步，確保每次都一樣）
子步長 1/240 秒，累積器跑 while 迴圈
加速度 = G·ty − 0.0008·v² − 0.15（重力分量、空氣阻力、滾動摩擦）
最低速度 10 m/s（出站時從 1.5 m/s 慢慢加上去），低於就當作被鏈條拉上坡，並觸發「喀喀喀」音效
剩下 14m 時開始煞車進站
乘客感受的 G 力 = (切線加速度＋v²·曲率 − 重力) 投影到座位法線方向，再做低通濾波；2D 小人依 G 力做出舉手、縮身的動作
出發前在車站停 2.2 秒（播鈴聲後放開煞車）
7. 2D 繪圖
背景（天空漸層、雲、地面）先畫到離屏 canvas 快取，resize 時才重畫
軌道：紅色雙軌＋枕木＋支柱，也快取成圖層
三節車廂（黃、藍、綠），每節有原創小人，手腳用簡單貝茲線，隨 G 力擺動
8. 3D 第一人稱（原生 WebGL）
2D 曲線放到 3D：x＝水平，y＝地面高度減 y，z＝依弧長慢慢變化的深度偏移，讓軌道有立體感
每點建立平移框架（切線 T、上方向 U 用 Gram-Schmidt 正交化、副法線 B＝T×U）
沿框架掃出管狀網格：左右兩條鐵軌（半徑 0.085、6 邊形）＋中間主樑，加上枕木、支柱、地面、遠山
自己寫一個簡單 Mesh 類別（push quad → Float32Array），以及頂點色＋方向光＋霧的 shader
鏡頭放在第一節車廂的位置，看向切線方向，上方向用 U
9. 聲音（Web Audio，不用音檔）
第一次觸控時才建立 AudioContext（iOS 限制）
風聲：白噪音經濾波器，音量與截止頻率跟著速度變
鏈條喀喀聲、出發雙音鈴聲、放開煞車的「鏗＋嘶」聲、進站煞車聲，全部用振盪器加噪音合成
10. 結束畫面
重搭一次、畫新的、存圖（把軌道畫到 canvas 後 toBlob 下載）、分享到 X（intent URL 加 hashtag）
鍵盤：Enter／空白鍵出發，M 鍵切換小地圖
完成條件
iPad Safari 與桌機 Chrome 都能畫、能搭，維持 60fps
同一個分享連結開十次，每次乘坐過程完全相同
畫一個圈時車子會倒過來，而且順利通過
整個網站只有一個 index.html，可以直接部署到 Cloudflare Pages
