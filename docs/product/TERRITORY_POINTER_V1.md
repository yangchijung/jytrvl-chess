# 領地爭奪戰｜指向與觸碰連續轉向 V1
日期：2026-10-19（Asia/Taipei）｜交接 Claude｜狀態：待實作

## 方向與理由
負責人轉述玩家回饋：「目前只有上下左右4個方向，建議改成滑鼠指標或手指碰觸就會改變方向，像真正的 papers.io2 那樣。」

目標是**指哪裡就朝那裡連續轉彎**：滑鼠不用按住，手機點下就轉、拖著可以持續改方向；可以斜走及畫出弧線。這是依回饋作的產品決定，不是競品實測紀錄。只借互動概念，使用 JY 原創畫面／素材／文案。

孩子的主要任務仍是離開領地、繞回來圈地。場地是主要畫面；一句提示說明控制，保留現有得分／暫停／結束資訊，不再加控制教學表單。遵守 DESIGN.md；本輪順手移除被改動 HUD 的玻璃效果、裝飾陰影及 emoji，不擴成全站改版。

## 原碼已確認的原因
以 main `baa2043` 查閱：
- `src/territory/TerritoryCanvas.tsx` 已有滑鼠跟隨，但用 abs(dx)>abs(dy) 量化成四方向；觸碰 pointerdown 只記起點，移動超過 22px 才轉；虛擬搖桿也量化四方向。
- `shared/territory/engine.ts`：Dir=0|1|2|3、每 100ms 移動一格、最多兩筆轉向佇列；不是只缺一個滑鼠事件。
- `client.ts`／`local.ts`／`online.ts` 與 `territoryProtocol.ts` 都傳 Dir；`TerritoryRoom.ts` 限制 d 在 0..3。渲染、AI、教學與房間快照也依賴此模型。

**把觸碰接成四方向或只加八方向不算完成。** 必須把移動／碰撞／圈地與網路輸入一同升級；先交本機可玩小段，不用等全站遷移才給試玩。

## 互動契約
| 輸入 | 行為 |
|---|---|
| 桌機滑鼠 | 遊戲區內 pointermove 更新目標指向，不需按鍵；以角色實際畫面位置到指標的向量計算。游標停著時朝該方向持續前進，接近死區不抖動、不原地繞圈 |
| 手機／平板 | pointerdown 當下就朝觸點轉；同一根手指移動時連續更新。不是必須先滑滿 22px 才有反應。抬手後保留最後方向，仍持續前進 |
| 離開／取消 | pointerup、pointercancel、失去 capture 清掉觸控狀態；保留最後合法航向。新一輪／重新連線不可沿用上一局的按壓狀態 |
| 鍵盤 | 保留 WASD／方向鍵。按鍵提供目標方向，與指標使用相同速度與轉彎規則；最後一次有效輸入接手，靜止的舊指標不搶回鍵盤 |
| 搖桿 | 作為可選替代，類比方向，不再量化四向；觸碰主區仍可玩 |
| 同機兩人 | 保留原本兩套鍵盤；觸控需各自區域／各自 pointerId 或各自搖桿，一指只控制一人。單一滑鼠不偷偷控制兩個人 |

- 使用相對角色畫面中心的方向，不用視窗中心；正確換算 canvas CSS 尺寸、DPR、鏡頭移動、縮放與旋轉後位置。
- 明確小死區，避免手指壓在角色上產生除零／亂轉；死區內維持航向。用有限、可調的轉向速率平滑靠近目標角度；指向後方以最短方向轉彎，不瞬間折返穿過自己。
- 主遊戲區處理 touch-action／pointer capture；頁首與按鈕不吞觸控、不要誤轉。第二根手指不能搶走第一根指標；暫停、倒數、死亡、結算時不能寫入有效移動。
- 本機切背景保留暫停既有行為；線上沿用斷線／代打規則，不擅改計分。
- 提示繁中「滑鼠指向哪裡，就往哪裡走」／觸控「點一下轉向，拖著改方向」；英文「Point to steer」／「Touch to turn. Drag to steer.」。可由實際輸入切換提示，不按年齡設門檻。
- 單次接觸即可操作，不要求長按、畫複雜手勢或只能拖曳；保留至少 44px 的替代控制與可見鍵盤焦點。

## 規則與工程範圍
- 持續前進，使用連續位置及 heading／標準化方向向量；不再將遊戲結果鎖在四向或八向。選擇固定模擬步長、有限轉向速率；斜走不能比直走快。
- 領土仍可在離散網格上儲存，但頭與尾線畫面連續。移動路徑必須掃過每段經過的格／線段，碰撞不能只看終點；回家封閉及圈地要與可見軌跡一致，斜線角落不能漏格、穿過細尾線或憑空多圈地。
- 保留離地留線、返家圈地、切線、出界及領土歸零等核心規則。重新定義連續移動中的頭碰頭、交叉、自己的新尾段保護／接縫判定，寫明可重播例子；不能用大範圍免死解決剛出門自撞。
- 渲染、鏡頭、預測與 AI 都用同一種座標／航向；AI 不可仍以另一套四向速度移動。教學「轉三次」不能因每幀角度小變化立即過關，改為有意義的三次方向改變。
- 線上仍由伺服器權威計算速度、位置、碰撞、圈地、勝負；客戶端僅送受驗證且限頻的目標方向。處理 NaN／Infinity／越界值；不得接受客戶端位置或得分。
- 版本化 protocol／snapshot／房間規則；本機預覽不改線上舊房。線上升級時，既有房間保持其開局版本或提供明確相容處理，不能把舊 0..3 當弧度讀；休眠恢復、重連與結束畫面均要回歸。
- 不為這次要求改換全站引擎或新增第三方帳號。可沿用 Canvas 2D；Three.js 是工具選項，不是前置條件。
