## 2. 設計方向與理由
**孩子的動作：選圖 → 混色 → 塗一下 → 讓作品動一下 → 換個配色試試。** 學習目標是觀察色彩變化及表達選擇，不宣稱已證實提升智力。

- 主要動作依情境只有一個：塗色時是點畫紙；需要混色時顯示「混一混」；想看動作時按「動一下」。
- 畫紙為主，色盤緊接畫紙，一次一條短提示。工具名稱配圖示，不靠 emoji 或大段說明。詳細原因放「為什麼」。
- 手機先看到作品與可點的色票，次要工具收在既有工具列；桌面沿用畫紙＋側邊工具。模板挑選用作品縮圖，首批最多三張，不做商店式長目錄。
- UI 沿用紙白／墨色／森林綠及既有字級。多色只出現在色票與孩子作品，沒有裝飾漸層、閃光或漂浮粒子。
- 保留自由畫作為直接入口；「玩圖畫」是新入口，不強迫先選課程。舊格子鍵盤玩法與六任務仍可使用。
- 輕鬆玩（5–7）：點區域填色，示範可以跳過；多試一點（8–12）：先猜、比較兩個版本、選自己的配色，無倒數或扣分。
- 以上為新玩法設計，尚未實作／試玩；不能把競品頁面說明當成我們的驗收結果。

## 3. 先做 B1：「我的小魚」
**先交這一張的可玩版，不必等整套素材與所有新模式。**

原創魚由身體、尾巴、魚鰭三個大區域組成；眼睛是固定辨識細節。B1 先做區域點填；可隨時切回既有自由畫，模板內自由筆畫留到後續，不作為第一張交付的門檻。低齡不必準確沿線，按區域即可。每區域同時有名稱、輪廓與可見焦點；較小魚鰭可透過對應的「魚鰭」按鈕操作，44×44 以上。

流程與完成定義：
1. 打開「玩圖畫」的小魚，畫紙已可操作，不先開說明框。
2. 可自由選色，也可按「試試混色」走紅＋黃→橙。這是既有配方／學習機制的情境化，不回報成新色彩知識。
3. 混色後結果、色名與「用這色畫」留在眼前；帶回畫紙並定位到可操作的區域。沿用已驗收的引導行為。
4. 自由玩法可任意配色；只要有一個區域上色即可按「動一下」，不以符合指定顏色或塗滿所有區域作為動畫門票。
5. 混色小任務的完成條件另行記錄：本次混過 mix_orange，且把 orange 用在至少一個區域。畫錯顏色仍保留作品，提示「也試試混出的橙色」；改色與復原都可行，不評美醜。
6. 按「動一下」，魚尾完成一次 200ms 的小幅擺動，使用孩子當前的顏色，不循環、不延遲下一筆。減少動態時直接顯示靜態姿勢或「完成」狀態，仍能繼續操作。
7. 可再改配色、復原／重做、保存 PNG；動作本身不算一筆畫，不污染畫作歷史。PNG 是穩定的靜態作品，無 UI。

核心雙語文案：
| 用途 | 繁中 | 英文 |
|---|---|---|
| 入口 | 玩圖畫 | Picture play |
| 第一提示 | 選個顏色，塗看看 | Pick a colour and paint |
| 混色入口 | 試試混色 | Try mixing |
| 選區域提示 | 點身體來上色 | Tap the body to colour |
| 結果動作 | 用這色畫 | Paint with this |
| 作品動作 | 動一下 | Make it move |
| 變化提示 | 換個顏色試試 | Try another colour |
| 區域名稱 | 身體／尾巴／魚鰭 | Body / Tail / Fin |
| 成功回饋 | 橙色用在小魚上了 | You used orange on your fish |

## 4. B2／B3 後續順序
B1 可玩且沒有存檔回歸後再接，不把它們綁成一次大改版。

| 增量 | 玩法 | 色彩學目標／判斷 |
|---|---|---|
| B2-a「兩種藍」 | 同一張小魚試藍與淺藍，並排比較兩版；孩子點選要保留的版本 | 既有 blue＋white→light_blue；比較加白後變亮。保存選擇，不把喜好判成對錯 |
| B2-b「花園配色」 | 原創花朵與葉片兩組區域，試橙色花＋藍色背景及另一組自選配色 | 觀察暖／冷差異；不規定顏色必然等於特定心情 |
| B3「一步畫看看」 | 三步可跳過的圖像引導：魚身、尾巴、細節；接受自由線條 | 表達與程序順序；不做線條像素比對、不給 AI 美術分數 |

B1 預設 Canvas 2D＋SVG／DOM 可完成。Three.js 依原授權可用於確有需要的場景，不能成為第一張交付的前置要求。美術可用 Figma／Canva／Higgsfield／Adobe 製作原創素材；先完成一張魚的身體與尾巴分層，附來源及製作方式，不等待大量產圖。

## 5. 存檔與工程邊界
已通過 D1–D4、D3-R1／D4-R1；本輪新增內容不能破壞這些修正。

- 場景狀態另行定義：版本、sceneId、各區域色彩、undo／redo、目前任務步驟；模板內自由筆畫日後擴充時另加。**不可把新的 scene 值直接寫入舊版只接受 free／grid 的 surface 欄位。**
- 優先以獨立版本化儲存保存場景作品，保留既有兩張紙與六任務；使用與現有相同的備份／另存／讀回驗證原則，不盲目清除或覆寫舊鍵。
- 混色仍採產品 JSON 的固定配方，首版魚用現有 mix_orange；場景視覺光線或材質不可改變教學色票。
- 舊作只讀遷移後重整可續畫；新區域填色、換色都可復原，既有自由筆畫回歸也要保留。新圖不可默默洗掉上一張；B1 只存一張小魚時，要提供確認與保存圖片入口。
- SVG 區域／畫紙尺寸改變使用正規化座標，手機旋轉後不漂移；不要把整頁禁止捲動。
- 作品仍在本機，不新增帳號、上傳作品牆、雲端 AI、廣告或付費依賴。
